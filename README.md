# 기관 CI · 슬로건 자료실

공식 기관 홈페이지에서 수집한 CI·슬로건의 검색 및 투명 PNG 다운로드 사이트입니다. GitHub Pages에서 서버 없이 실행됩니다.

프로그램 코드는 MIT 라이선스입니다. 이미지와 기관 상징에는 MIT 라이선스가 적용되지 않으며 각 기관의 권리 및 이용 조건을 따릅니다. 자료별 공식 출처와 처리 방법을 상세 화면에 표시합니다. 일부 이미지는 배경 제거·PNG 변환된 파일입니다. 이 사이트는 비공식 자료 모음이며 기관의 보증을 의미하지 않습니다.

현재 507개 기관, 1241개 자료를 수록하며 미확보 항목도 표시합니다.
